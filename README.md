# Weekly Store Sales Analyzer

A Python program that analyzes weekly store sales data from CSV files using NumPy.

## Features

- Reads store sales data from CSV files
- Converts sales data into NumPy arrays
- Calculates total and average sales
- Finds maximum and minimum sales values
- Generates an output file containing the analysis results

## Technologies Used

- Python
- NumPy
- CSV
- pathlib
